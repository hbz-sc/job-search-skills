# JobPilot 自动重绑与安全恢复

用户选择“按推荐直接实现”，明确跳过额外方案确认。沿用现有 Edge、TypeScript/LangGraph/SQLite 和已授权联系范围。

首次手动连接建立当前浏览器会话内的标签授权。相同 tabId 的 BOSS jobs/chat 文档刷新后立即撤销旧文档绑定、停止旧租约；等待页面可读并重新注入固定打包内容后，发布新 documentId。延迟完成的旧恢复不能覆盖新页面，也不能在主动断开后复活。不会寻找其他标签、自动重新打开已关闭标签、越过登录/验证码或在浏览器重启后恢复授权。

扩展每次恢复最多尝试3次；本地 search 批次的自动续跑预算持久化为3次，手动恢复和进程重启不重置。客户端重连后建立新租约，额度仅为原批次剩余量，恢复现有图/账本。只有明确的连接/文档故障可重试；未知发送、身份/话术/筛选/额度异常暂停。原请求不换 envelope 重放。所有恢复等待计入活跃预算，崩溃时保留保守预占。

选择的方案：自动重绑并安全续跑，减少人工点击；仅重绑更简单但仍需手动恢复任务。大模型自由选择标签/重试动作增加不可预测性且无必要，采用确定性恢复状态机。

边界：search CLI 在运行期间自动恢复；已经退出的 CLI 不会由扩展偷偷启动，需要原来的 resume 命令。没有守护进程或计划任务。原有实站经验筛选/常用语加载验收继续保留。

# 工作经验菜单：方案 B 简短设计

状态：用户已选择方案 B；本文待确认，尚未修改产品代码或扩展权限。

## 目标与依据

在现有 Edge BOSS 页面扩展中自动展开工作经验菜单，并分别完成深圳、1–3 年和 3–5 年的查询，不需要用户保持鼠标悬停。继续使用现有 TypeScript / LangGraph / Python 桥，不增加逐岗位模型调用。

方案 A 实站实验中，向经验容器及触发器派发 mouseover/mouseenter 后，8 次有界观察均未看到菜单，最终 FILTER_UNVERIFIED；联系额度和实际联系均为 0。已恢复实验前的加载文件，正式源码未改。此结果说明该合成事件实现无效，不足以证明网站一定使用纯 CSS。

## Approaches

- A：内容脚本触发鼠标进入事件。无需新增权限、改动小，但本次真实页面未展开，停止沿此实现反复尝试。
- B（用户选择）：扩展通过浏览器调试接口发送指针移动及点击，内容脚本定位和核验控件。能够测试实际浏览器悬停机制，代价是新增 debugger 权限和调试会话管理。
- 桌面坐标自动化：依赖前台窗口和系统坐标，当前电脑控制接口还存在网址识别阻塞；不作为项目长期实现，也不通过替代接口绕过该工具的安全停止。

## 权限与范围

采用 manifest 的必需权限 debugger。官方文档明确 debugger 不支持 optional_permissions，不能设计成运行时申请可选权限。现有 host_permissions 保持 https://www.zhipin.com/*。

必须准确告知：debugger 本身是较宽的浏览器调试权限，不能声称浏览器将其限制为仅 BOSS。项目代码额外限制为当前明确绑定的 BOSS 职位标签、顶层文档、有效请求和有效运行租约；仅开放固定经验控件的输入操作。浏览器可能显示调试提示。

先完成代码、测试和构建供检查，再安排用户加载扩展更新、核对新增权限。设计确认不代替浏览器实际授予权限；不自动接受权限提示。

不提供任意 CDP、坐标、选择器或脚本执行的 MCP 工具。不开调试端口，不读取 cookies、网络响应或其他标签，不扩大聊天和发送能力。

## 实现边界（实现者建议）

1. 内容适配器定位唯一经验容器、可见触发器，读取当前文档和视口内的控件矩形。必要滚动在现有授权检查后进行；不缓存屏幕绝对坐标。
2. 后台增加专用经验指针执行器。限定由已有 v3 search_jobs / restore_search 的筛选阶段调用，目标档必须来自批次 scope。模型不能提供点击点。
3. 校验绑定、URL、文档、租约、截止时间、登录/验证提示后，附加到目标标签，使用 Input.dispatchMouseEvent 进行浏览器级 mouseMoved。坐标使用页面视口 CSS 像素，不按系统缩放重复换算。
4. 等待菜单可见后，由内容脚本重新读取唯一目标选项的位置。校验可见性、遮挡和精确文字，再移动指针到选项；菜单仍可见且命中正确选项时才点击。指针移动途中若菜单收起，最多重新展开一次；不能直接点击隐藏项或强改样式。
5. 读取实际选中证据；只有真实观察到的标记才可作为依据。如果是多选，先读取已选项，再通过同一路径取消非目标档，确保查询档唯一；若选中状态无法确定则暂停。
6. 沿用现有深圳、关键词、经验和结果更新检查，未通过就不进入后续岗位处理。不得以发送过鼠标命令或 URL 正确替代筛选成功。
7. 同一时间只允许一个指针操作。每个动作前后检查文档代次与停止信号。绑定变化后废弃旧坐标，重新观察；已产生点击而结果未知时先检查选中状态，不盲目补点。
8. 本次取得的调试连接在成功、失败、超时、停止或权限撤销后清理；连接尚在建立时发生取消，也须在其完成后清理。发现调试器占用或附加被拒绝则明确暂停，不接管、断开其他控制器，不反复争抢。鼠标按下/松开异常要清理自身输入状态，不能留下拖拽状态。

改动范围：经验筛选适配器、content/background 消息校验、workflow-controller、专用指针模块、扩展 manifest/构建权限白名单、必要的状态提示及回归。保持现有公开搜索工具契约、批次额度、历史去重和未知发送策略。

## 失败信息

至少区分调试权限/附加失败、调试连接被关闭、经验菜单未展开、选项缺失或歧义、选中状态不匹配、结果未更新、绑定变化和用户停止。明确错误必须保留到日志及用户状态，不能全部吞掉变成含糊的超时。重试仍受原请求截止时间和既有批次恢复上限约束，不增加无限恢复循环。

## 验收与交付

- 本地真实浏览器 fixture：纯 CSS hover 菜单能展开；两档往返切换；隐藏或重复项不误点；位置变化、遮挡、菜单收起时停止或有界重新定位。
- 会话回归：取消发生在 attach 中、刷新发生在移动与点击间、调试器冲突、权限撤销、超时与主动断开均清理自身连接；不影响既有发送账本和去重。
- 实站先执行零联系 preview：至少两个关键词分别验证深圳与两档经验，不需要用户悬停；记录真实选中证据、结果变化、每步失败原因。
- 在筛选期间刷新一次，验证同标签重绑后重新定位，不沿用旧坐标。无成功证据就不宣称实站通过。
- 此增量不发送消息。历史未知发送和第一条常用语来源就绪仍是后续真实打招呼的独立验收项。
- 完成后讲解“工具实现与图节点分工、观察后再行动、持久化状态与浏览器临时状态的区别”，并按原要求进行统一代码审查。保留回退构建，不创建 Git 仓库。
